## Getting Started

Each experiment folder contains an independent Flutter application structure with:
- `lib/main.dart` - Complete source code for the experiment
- `pubspec.yaml` - Dependencies and configuration
- `README.md` - Aim, description, and instructions for running the experiment

To run any experiment:
```bash
cd <Experiment_Folder>
flutter pub get
flutter run -d chrome
```
