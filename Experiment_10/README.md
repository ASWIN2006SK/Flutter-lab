# Experiment 10: Manual User Login Authentication Using Google Firestore Database

## Aim
To develop a Flutter application that allows users to register and log in using email and password credentials stored in Google Cloud Firestore, and displays a dashboard after successful authentication.

## Description
In this experiment, a Flutter application named Secure Login is developed to demonstrate manual user registration and login using Google Cloud Firestore. The application provides registration and login interfaces with email and password input fields. During registration, the entered email address is converted to lowercase and used to generate a document identifier. A random salt is generated, and the password is combined with the salt and hashed using the SHA-256 algorithm provided by the crypto package. The email address, salt, password hash and server timestamp are stored in the Firestore 'users' collection. During login, the application retrieves the corresponding user document, reads the stored salt and password hash, hashes the entered password using the same salt, and compares the result with the stored hash. If the values match, the application navigates to a dashboard displaying the logged-in email address. Otherwise, an appropriate error message is displayed. The interface also supports switching between registration and login, showing or hiding the password, and logging out to return to the login screen. Firebase is initialized using Firebase.initializeApp() with the configuration generated by the FlutterFire CLI. The application was executed in Google Chrome and tested with registration and successful login. This is a classroom demonstration of manual credential checking; production applications should use a dedicated authentication service.
