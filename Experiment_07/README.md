# Experiment 7: Data Persistence Using Google Cloud Firestore

## Aim
To design and develop a Flutter application that stores and retrieves student information using Google Cloud Firestore, demonstrating cloud-based data persistence through Create and Read operations.

## Description
Cloud Firestore is a NoSQL cloud database provided by Firebase. It stores data as documents organized into collections and synchronizes changes in real time. In this experiment, a Flutter application named StudentHub Cloud is developed to register student details and retrieve the stored records from a Firestore collection named 'students'. The application collects the student's name, register number, department and email address. When the Save Student button is pressed, the add() method of the Cloud Firestore collection reference creates a new document containing these fields and a server timestamp. A StreamBuilder listens to the collection's snapshots() stream and displays the student records in the application. This stream-based approach updates the displayed list when Firestore data changes. Firebase is initialized in the main() function using Firebase.initializeApp() and the platform-specific configuration generated by the FlutterFire CLI. The application was executed in Google Chrome, and the saved student document was verified in the Firebase Console.
