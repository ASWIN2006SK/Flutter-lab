# Experiment 8: Searching Information in Google Firestore Database

## Aim
To develop a Flutter application that retrieves information from Google Cloud Firestore based on user search input and displays the relevant student information on the screen.

## Description
Google Cloud Firestore is a cloud-hosted NoSQL database that stores data in collections and documents. In this experiment, a Flutter application named Student Search is developed to search for student information stored in the 'students' collection created in Experiment 7. The application provides a text field in which the user enters a student's name. When the Search button is pressed or the Enter key is submitted, the application performs a Firestore query using the where() method with isGreaterThanOrEqualTo and isLessThanOrEqualTo conditions. The query retrieves names beginning with the entered search text. The get() method fetches the matching documents from Firestore. The results are stored in a list and displayed using ListView.builder and ListTile widgets. If no matching document is found, the application displays an appropriate message. A clear button resets the search field and removes the displayed results. Firebase is initialized using Firebase.initializeApp() and the configuration generated by the FlutterFire CLI. The application was executed in Google Chrome and successfully retrieved the student record for the search term 'Santhosh'.
