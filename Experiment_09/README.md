# Experiment 9: Update Information in Google Firestore Database

## Aim
To develop a Flutter application that updates existing student information in Google Cloud Firestore based on user input and displays the updated information on the screen.

## Description
Google Cloud Firestore is a cloud-hosted NoSQL database that stores information in collections and documents. In this experiment, a Flutter application named Student Update is developed to modify student information already stored in the 'students' collection. The user enters a student's register number and selects the Find Student button. The application searches Firestore using the where() method with an equality condition on the registerNumber field. If a matching document is found, its document ID and current student details are retrieved and displayed in editable text fields. The user can modify the student's name, department and email address. When the Update Student button is pressed, the application uses the Firestore document reference and update() method to modify the existing document. The register number is used to identify the record and is not changed. A success message is displayed after the update operation completes. Firebase is initialized using Firebase.initializeApp() and the configuration generated by the FlutterFire CLI. The application was run in Google Chrome, and the successful update operation was verified by the displayed confirmation message.
